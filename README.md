Blog Application

## Overview

This is a simple blog application built with React and Firebase. It allows users to create, view, and delete blog posts. The application features a clean and responsive design, ensuring a seamless user experience across devices.

## Features

- Create new blog posts with titles and content.
- View a list of existing blog posts.
- Delete blog posts with confirmation.
- Toast notifications for successful actions and errors.
- Responsive design for mobile and desktop users.

## Technologies Used

- **Frontend**: React
- **Backend**: Firebase Firestore
- **Styling**: Tailwind CSS
- **Notifications**: React-Toastify
